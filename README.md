# پزشک‌یار

یک محصول کامل «یافتن پزشک و رزرو آنلاین نوبت» به فارسی و راست‌به‌چپ؛ از جستجو و مقایسهٔ پزشکان تا تقویم جلالی، انتخاب ساعت، فرم اطلاعات و صفحهٔ موفقیت با کد پیگیری. طراحی موبایل‌محور با ظاهر حرفه‌ای، بدون بک‌اند — داده‌ها نمونه (mock) هستند.

## ویژگی‌ها

- **صفحهٔ اصلی** — جستجوی سه‌فیلدی (تخصص/دکتر، شهر، زمان)، اقدامات سریع، بخش تخصص‌ها، پزشکان برتر، چرا پزشک‌یار؟، نظرات بیماران و سؤالات متداول
- **جستجو و کشف پزشک** — فیلتر تخصص، شهر، قیمت، امتیاز، جنسیت، زمان و «فقط مشاوره آنلاین»؛ در دسکتاپ سایدبار و در موبایل پایین‌برگ (Bottom Sheet)
- **پروفایل پزشک** — هرت با عکس و نشان تأیید، شمارهٔ نظام پزشکی، امتیاز و توزیع نظرات، تب‌های درباره / خدمات / نوبت‌ها / نظرات
- **روند رزرو پنج‌مرحله‌ای** — نوع ویزیت → تقویم جلالی (امروز تا ۴۵ روز آینده) → ساعت‌ها (نوبت‌های پر غیرفعال) → اطلاعات شما → تأیید نهایی؛ با خطاگیری فرم و دکمهٔ چسبان در موبایل
- **صفحهٔ موفقیت** — بلیت نوبت، کد پیگیری قابل کپی و «مشاهده نوبت»
- **حساب کاربری** — نوبت‌های آینده/گذشته با وضعیت‌ها (تأیید شده، در انتظار، لغو شده، انجام شده)، لغو نوبت با تأیید، علاقه‌مندی‌ها، پروفایل، آدرس‌ها و اعلان‌ها
- **کلینیک‌ها، مجلهٔ پزشکی** (۶ دسته)، **تخصص‌ها** و صفحهٔ ۴۰۴
- **ورود/خروج نمایشی** با ذخیره در مرورگر (بدون ارسال به هیچ سروری)

## کیفیت

- فارسی کامل و RTL با فونت وزیرمتن؛ اعداد فارسی؛ قیمت‌ها به تومان
- پالت ثابت آبی روشن (سطح `#F5FAFD`، اصلی `#74B9E8`، تیره `#174A6B`)
- موبایل‌محور: ناوبری پایین، تقویم و ساعت مناسب لمسی، نوار CTA چسبان، بدون اسکرول افقی در عرض‌های ۳۶۰ تا ۴۳۰
- دسترسی‌پذیری: HTML معنایی، ناوبری صفحه‌کلید، focus-trap در مودال‌ها، aria-label/aria-live/aria-expanded/aria-pressed، کنتراست مناسب
- PWA: manifest و قابلیت نصب؛ SEO: عنوان و توضیحات اختصاصی هر صفحه، Open Graph، favicon
- بهینه: code-splitting مسیرها (React.lazy + Suspense)

## ساختار

```
src/
  components/   # ui (مودال، شیٔت، فیلد، دکمه…) + layout + booking + doctors + home + …
  context/      # AppContext: کاربر، علاقه‌مندی‌ها، نوبت‌ها، توست
  data/         # داده‌های نمونه: ۲۰ پزشک، ۱۲ تخصص، ۱۰ کلینیک، ۳۰ نظر، ۱۵ مقاله…
  hooks/        # عنوان صفحه، بارگذاری شبیه‌سازی‌شده، رفتار دیالوگ (focus-trap)
  lib/          # تقویم جلالی، اعداد فارسی، ابزارک‌ها
  pages/        # یک فایل برای هر مسیر
```

## راه‌اندازی

```bash
npm install
npm run dev      # توسعه روی http://localhost:5173
npm run build    # خروجی production در dist/
npm run preview  # پیش‌نمایش خروجی production
```

## تکنولوژی

React 18، Vite، TypeScript (strict)، Tailwind CSS، React Router، Lucide Icons، jalaali-js، فونت وزیرمتن (@fontsource)

> این پروژه یک نمونهٔ نمایشی است؛ اطلاعات پزشکان، کلینیک‌ها و نوبت‌ها جعلی هستند و هیچ داده‌ای ارسال نمی‌شود.
